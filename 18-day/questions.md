# ❓ Preguntas de Objetos, Dates y Arrays

---

## Easy 🟩

1.  ¿Podemos crear un objeto en JavaScript con `const` y de igual forma modificar las propiedades del objeto? (True o False)

2.  ¿Podemos anidar un objeto adentro de otro objeto? (True o False)

---

## Medium 🟨

1.  ¿Un objeto en JavaScript es considerado un valor *falsy* o un valor *truthy*?

2.  ¿Con qué *keyword* podemos borrar una propiedad de un objeto?

3.  El método `JSON.stringify()` convierte objetos a *strings* con formato JSON. (True o False)

4.  ¿Cuál es la manera correcta de comprobar que un array sea realmente un array?

---

## Hard 🟥

1.  ¿Podemos acceder a la propiedad de un objeto por medio de una expresión? (True o False)

2.  ¿Para qué nos sirve el método `Object.values()`?

3.  ¿Es válida la siguiente forma para crear un objeto de tipo `Date`? `const d = new Date("2022-03-25");`

4.  ¿Desde qué fecha se guardan los números de milisegundos para las fechas en JavaScript?
